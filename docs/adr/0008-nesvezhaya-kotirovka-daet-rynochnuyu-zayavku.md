# Несвежая котировка переводит строку в рыночный режим, а не блокирует пачку

Возраст стакана проверяется по `ob_ms_timestamp` на каждой генерации. Строки,
чья котировка старше порога шаблона, уходят рыночными; это видно построчно
в предпросмотре.

> Частично отменён ADR-0012: рыночная заявка подаётся с `Цена=0`, а не по
> наихудшей допустимой цене дня. Правило деградации лимитной цены в рыночную —
> ниже — действует без изменений.

## Considered Options

Блокировать генерацию отвергнуто: на экспирации в пачке почти всегда есть
неликвид по одному контракту без стакана, и правило «всё или ничего» означало бы,
что лимитный режим не включается никогда. Строить лимитную цену от устаревшей
котировки отвергнуто отдельно: незакрытая позиция уезжает на поставку, а это
дороже проскальзывания.

## Consequences

Правило двухуровневое. Котировки недоступны как источник — нет входа, нет
токена, Alor не ответил — вся пачка рыночная с явным сообщением о причине.
Источник ответил, но по отдельным инструментам стакана нет — рыночными уходят
только они, с перечислением тикеров.
