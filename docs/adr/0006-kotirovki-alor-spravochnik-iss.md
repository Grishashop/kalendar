# Котировки берём у Alor, справочник контрактов — у MOEX ISS

Цена для лимитной заявки строится по стакану Alor, а состав и параметры
контрактов — по публичному справочнику MOEX ISS. Разделение вынужденное:
ISS отдаёт рыночные данные с задержкой ровно 15 минут, что для заявки в день
поставки непригодно, зато его справочная часть — единственный источник признака
поставочности.

## Considered Options

Замер 07.08.2026 в 18:30 MSK по ликвидным контрактам показал у ISS
`SYSTIME − TIME = 15 минут` (SiU6, RIU6, GZU6, VBU6). Анонимный Alor в тот же
момент отставал ещё сильнее — возраст стакана VBU6 около 30 минут при
сегодняшнем обороте 167 800 контрактов, то есть это задержка ленты, а не мёртвый
инструмент. Пригодны только данные Alor с рабочим refresh-токеном.

## Consequences

Функция лимитных цен неработоспособна без валидного `ALOR_TOKEN`; при его
отсутствии страница честно сообщает об этом и оставляет рыночный режим.
Признак `EXECTYPE` есть только в карточке инструмента, не в массовой выдаче
FORTS, поэтому запрашивается по одному разу на базовый актив — он постоянен по
всем сериям одного актива — и кэшируется на торговый день.

ISS периодически отвечает по отдельным карточкам дольше таймаута — на живом
прогоне так повёл себя `SiU6` при исправных соседях. Поэтому неудача карточки
сужается до своего базового актива: после повторной попытки поставочность
становится «неизвестна», а не «расчётный», строка помечается как непроверенная
и остаётся в пачке. Обратное — исключить строку по незнанию — отправило бы
контракт на поставку.
